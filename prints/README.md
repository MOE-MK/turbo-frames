# Turbo35 3D-printed parts

Camera mounts, front lip bumper, antenna mounts and battery pad for the Turbo35.
Also on Printables: https://www.printables.com/model/983603-turbo-35-fpv-frame-parts

| File | Part |
|---|---|
| `turbo35/o4-pro-mount-left.3mf` / `o4-pro-mount-right.3mf` | DJI O4 Pro camera mount (L/R) |
| `turbo35/o4-bumper.3mf` | O4 bumper |
| `turbo35/dji-o3-camera-mount.3mf` | DJI O3 camera mount |
| `turbo35/o3-cam.stl` | O3 cam mount |
| `turbo35/hdzero_nano_90_camera_mount.3mf` | HDZero Nano 90 camera mount |
| `turbo35/universal-cam.stl` | Universal camera mount |
| `turbo35/turbo_16mm_fpv_cam.stl` | 16 mm FPV camera mount |
| `turbo35/turbo-gopro.stl` | GoPro mount |
| `turbo35/bumper.stl` | Front lip bumper |
| `turbo35/elrs-antenna.3mf` | ELRS antenna mount |
| `turbo35/turbo-antenna-mount.stl` | Antenna mount |
| `turbo35/turbo-35-battery-pad.3mf` | Battery pad |

The Printables listing also includes the **Warren Davis O3 Air Camera Mount (L/R)**, which is a third-party design and isn't redistributed here. Download it from the Printables page above.
